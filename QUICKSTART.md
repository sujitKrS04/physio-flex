# 🚀 Quick Start Guide

Get Physio-Flex running in 60 seconds!

## Step 1: Start Local Server

Choose one method:

### Option A - Python (Easiest)

```bash
cd Physio-Flex
python -m http.server 8000
```

### Option B - Node.js

```bash
npx http-server -p 8000
```

### Option C - VS Code

1. Install "Live Server" extension
2. Right-click `index.html`
3. Click "Open with Live Server"

## Step 2: Open Browser

Navigate to: `http://localhost:8000`

## Step 3: Use the App

1. **Grant camera permission** when prompted
2. **Select an exercise** from dropdown
3. **Click "Start Camera"**
4. **Position yourself** so full body is visible
5. **Start exercising!** 💪

## Tips for Success

✅ **Good Lighting**: Face a window or use bright lights  
✅ **Full Body Visible**: Stand 6-8 feet from camera  
✅ **Contrasting Colors**: Wear different color than background  
✅ **Stable Camera**: Place laptop/phone on stable surface  
✅ **Slow & Controlled**: Focus on form over speed

## Troubleshooting

### Camera not working?

- Check browser permissions (🔒 icon in address bar)
- Reload page and click "Allow"
- Try different browser (Chrome recommended)

### Skeleton not appearing?

- Step back to show full body
- Improve room lighting
- Wait 2-3 seconds for AI to load

### Reps not counting?

- Check form quality indicator (aim for green)
- Ensure full range of motion
- All joints must be visible

## Exercise Recommendations

### Advanced Users Try:
